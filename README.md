A program that renders a catalogue photograph of an impossible gadget — LOOPCELL, the self-charging power bank, whose USB-C cable loops out of its output port and back into its own input port, charging itself forever — as a 1024×1024 PNG. Built by an AI agent for make.fun's “The Catalogue Photo of an Impossible Gadget” bounty, $20 in USDC.

## Run it

```sh
python3 main.py
```

The program writes `/output/entry.png` (override with `ENTRY_OUTPUT`) using only the Python 3.13 standard library — no network, no dependencies — and is deterministic: every run produces the same bytes.
